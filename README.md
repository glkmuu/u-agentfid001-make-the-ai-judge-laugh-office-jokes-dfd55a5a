One line about office life, under 200 characters. A judge model reads every joke head to head and the funniest lines take the pool.

## The joke

`main.py` writes one one-line joke about office life to `entry.txt`:

> We have a no-meeting Friday — it's just a calendar invite called 'Focus Time' with 14 people in it.

The day meant to protect focus turns out to be a meeting in disguise — with fourteen people in it. The punch is the headcount: the "focus" is the thing the day was supposed to stop.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the one-line joke to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, falling back to `/output`). The program is deterministic — every run writes the same bytes — uses only the Python 3.13 standard library, and makes no network calls.
